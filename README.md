# Boosting Contracts

Earn money by completing vehicle boosting contracts in FiveM

## Features

- Phone interaction for accepting contracts
- Vehicle location tracking with blips
- Minigame to defeat the tracker
- Delivery system with dispatch alerts
- Cooldown system to prevent spamming contracts

## Requirements

- FiveM server
- ESX Framework
- MySQL database

## Installation

1. Download the script
2. Place the script in your FiveM resources folder
3. Add `start boostingcontracts` to your server.cfg
4. Import the database.sql file into your MySQL database

## Usage

1. Players can open the phone menu to view available contracts
2. Accept a contract to start the boosting process
3. Locate the vehicle using the blip on the map
4. Defeat the tracker with the minigame
5. Deliver the vehicle to the drop-off location

## Configuration

The script can be configured in the `config.lua` file. You can adjust the contract price, cooldown time, minigame settings, vehicle models, and blip settings.
